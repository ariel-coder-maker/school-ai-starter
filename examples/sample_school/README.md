# Sample school: Example Academy

A fictional school, filled in, so you can see the kit working before you set
up your own. Its framework is invented for the example. It is not the IB's or
any real program's.

**To try it** (on a copy of the kit, not your real one): copy the four folders
here (`00_school/`, `01_curriculum/`, `03_resources/`, `05_checks/`) into the
kit's main folder. Then, at Level 1, ask your AI tool to `make a unit` for
Grade 7 Science, Term 1, "Forces". At Level 2, set `ENGINE_PRACTICE=1` in
`engine/.env` to run the whole engine with worked examples and no AI cost.

Delete the copied folders before running `setup` for your real school.
