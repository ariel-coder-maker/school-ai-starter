# Where to start, by role

Everyone types `setup`. Your answer to the first question (A1) decides where
it starts and what it skips.

| You are | You own | Start with | First win |
|---|---|---|---|
| **Teacher** | Your subject's folder (if nobody else has set it up), your outputs | Level 1, one course. If a coordinator already filled `00_school/`, setup skips straight to your subject | One lesson or worksheet you'd actually teach next week |
| **Department head / subject lead** | `01_curriculum/<subject>/`, `02_sources/`, the subject's checks | Level 1. Verify the subject's framework once, so every teacher in the department builds on the same criteria | A verified `framework.md` and one unit outline the department agrees on |
| **Curriculum or program coordinator** | `00_school/`, the shared checks, who approves what | Level 1 for the school layer, then one pilot department | A school layer every teacher inherits: calendar, unit shape, assessment, planner fields |
| **IT director** | Where the folder lives, which AI providers are allowed, the engine, keys, backups | Level 1 on a shared drive, then Level 2 on one machine, then Level 3 | A shared folder with the right permissions, and a written list of approved AI providers |
| **School leader** | The calendar and policies, the AI-use policy, budget, who owns what | Answer B1, B7, B9 and D6, then name a coordinator | A named owner for the school layer, and one pilot |
| **Lab technician / resources** | `03_resources/` | C7–C10 only | An inventory the AI plans around, and a term order list |

## Using only one part

You don't have to set up everything.

| You want | Set up | Then type |
|---|---|---|
| **Better materials for units you already have** | Blocks A and B (or use the coordinator's), your subject folder, and paste your existing unit into `01_curriculum/<subject>/units/` | `make a worksheet`, `make slides` |
| **A second opinion on things you made elsewhere** | Blocks A and B, and `05_checks/` | `check this` |
| **A materials order list for next term** | Block B (calendar), C7–C10 (resources), and the term's units | `make the order list for term 1` |
| **The school layer for colleagues who use any chatbot** | Blocks A and B only. Colleagues upload `00_school/` to their own chatbot as context | — |
| **Assessment that matches your criteria** | Blocks A–C with a **verified** framework | `make a rubric` |

## Who should not do what

- Teachers shouldn't change `00_school/` on their own: everyone inherits it. Ask the owner (B9).
- Nobody puts student names, grades or reports in this folder.
- Only the budget holder (D6) raises the spending limit.
