# Any program — starting defaults

Setup copies this into `00_school/` when the program (A8) is not IB MYP: AP,
IGCSE, A Level, a national curriculum, state standards, IB DP or PYP, or a
school's own. Almost everything here is a question, not a default. Programs
differ too much to guess.

## What works for any program

- **Units are built in steps:** outline first, then lessons, then assessment.
  A person approves each step before the next.
- **Every lesson has:** a learning objective someone could observe being met
  ("students can explain…", never "students understand…"), a way to check
  understanding before the lesson ends, and timings that add up to the taught
  minutes.
- **Every assessment** names what it assesses, using the codes in the
  subject's `framework.md`. Nothing is assessed that wasn't practised first.
- **Every mark scheme or rubric** describes only what the task asked.

## What setup must ask you (no defaults)

| Setting | Question |
|---|---|
| Terms, learning weeks, period length | B1–B3 |
| Unit shape and where assessments sit | B4 |
| Grading scale, and how a final grade is reached | B5 |
| What a unit and a lesson plan must contain | B6 |
| The assessment framework itself, for each subject | C2, using `framework_template.md` |
