# IB MYP criteria

Criterion names for all eight MYP subject groups, from the IB's public subject
briefs. Setup copies the subject's file to `01_curriculum/<subject>/framework.md`.

**Strand wording is deliberately not included.** It's in each subject's guide,
which schools get from the IB programme resource centre. Setup asks you to
supply it, and nothing assessed is generated until a person has checked it.

| Subject group | File | Criteria |
|---|---|---|
| Sciences | `sciences.md` | A Knowing and understanding · B Inquiring and designing · C Processing and evaluating · D Reflecting on the impacts of science |
| Design | `design.md` | A Inquiring and analysing · B Developing ideas · C Creating the solution · D Evaluating |
| Arts | `arts.md` | A Investigating · B Developing · C Creating or performing · D Evaluating |
| Individuals and Societies | `individuals_and_societies.md` | A Knowing and understanding · B Investigating · C Communicating · D Thinking critically |
| Language Acquisition | `language_acquisition.md` | A Listening · B Reading · C Speaking · D Writing |
| Language and Literature | `language_and_literature.md` | A Analysing · B Organizing · C Producing text · D Using language |
| Mathematics | `mathematics.md` | A Knowing and understanding · B Investigating patterns · C Communicating · D Applying mathematics in real-life contexts |
| Physical and Health Education | `physical_and_health_education.md` | A Knowing and understanding · B Planning for performance · C Applying and performing · D Reflecting and improving performance |
