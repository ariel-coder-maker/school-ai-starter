# <Subject>

Setup copies this folder to `01_curriculum/<subject>/` for each subject.

| File | What it holds | Question |
|---|---|---|
| `framework.md` | The criteria or assessment objectives, with strands, from an official document. **IB MYP:** start from `tracks/ib/criteria/`. **Any other program:** start from `tracks/general/framework_template.md`. `UNVERIFIED` until a person checks it | C2 |
| `standards.md` | The standards you align to, with their real codes, copied from the official source (NGSS, Common Core, AERO, a national framework). Leave it out if you don't align to any | C3 |
| `scope_and_sequence.md` | Which units are taught in which grade and term, in order, and the textbook chapters each one uses | C4 |
| `constraints.md` | Topics to avoid, cultural considerations, local examples to use | C6 |
| `units/` | Approved unit plans, one file per unit. Lessons are generated from these | made by `make a unit` |
